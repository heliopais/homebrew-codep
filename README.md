# Heliopais Codep

## How do I install these formulae?

`brew install heliopais/codep/<formula>`

Or `brew tap heliopais/codep` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "heliopais/codep"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
